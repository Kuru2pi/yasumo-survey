# みんなの休み方調査

PROJECT Yasumo の調査で、聞き取りをしながらその場で記録するための個人用Webアプリです。
スマホ・iPad（Apple Pencilでの手書きメモ付き）で使います。

- 公開ページ: https://kuru2pi.github.io/yasumo-survey/
- ファイルは `index.html` 1つだけです。

## データの扱い

- 回答はすべて、使っている端末のブラウザの中（localStorage）にだけ保存されます。サーバーには送りません。
- このリポジトリと公開ページに、回答データは含まれません。
- 書き出し（CSV・JSON）はアプリ内の「データを書き出す」から行います。こまめにバックアップしてください。

## 使うときの注意

- iPadでは、Safariのタブで使うか、ホーム画面に追加して使うかを、どちらかに決めてください。保存場所が別になります。
- Safariは、しばらく開かないと保存データを消すことがあります。調査の合間にも書き出してください。
